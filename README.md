# Service Deck

服务管理工具 - 管理和监控本地服务

## 技术栈

- **前端**: React + TypeScript + Tailwind CSS
- **后端**: Rust + Tauri 2
- **图标**: Lucide React

## 开发环境

### 前置要求

- Node.js >= 18
- pnpm
- Rust (最新稳定版)

### 安装依赖

```bash
pnpm install
```

### 启动开发

```bash
pnpm dev
```

### 构建

```bash
pnpm build
```

## 功能

- 添加/删除服务（支持基础服务和项目服务分类）
- 启动/停止/重启服务
- 服务状态实时监控
- 实时日志查看（支持暂停/继续滚动）
- 项目管理（一键启动/停止多个服务）
- 拖拽排序
- 搜索过滤
- 设置面板（配置文件路径）

## 服务配置说明

### 基本配置

| 字段 | 说明 |
|------|------|
| 服务名称 | 显示名称 |
| 工作目录 | 服务可执行文件所在目录 |
| 启动命令 | 在工作目录下执行的命令 |
| 启动类型 | 自动（项目启动时自动运行）/ 手动 |
| 环境变量 | 可选，格式 `KEY=VALUE`，会注入到进程环境 |
| 日志路径 | 可选，填文件路径读取指定日志，填目录路径自动找最新日志文件 |

### Tomcat 配置（特殊）

Tomcat 的 `startup.bat` 会弹出新窗口，且 Java 进程日志通过 pipe 捕获不完整。需要特殊配置：

| 字段 | 值 |
|------|---|
| 启动命令 | `catalina.bat run` |
| 工作目录 | `D:\path\to\apache-tomcat-9.x.x\bin` |
| 日志路径 | `D:\path\to\apache-tomcat-9.x.x\logs`（填目录） |

**注意：**
- 启动命令必须用 `catalina.bat run`，不要用 `startup.bat`（会弹窗）
- 日志路径填 Tomcat 的 `logs` 目录（不是具体文件），工具会自动找到最新的 `.out` 日志文件
- 不填日志路径则只显示控制台输出（不完整）
